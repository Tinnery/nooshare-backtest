# 执行模型实现契约

本文描述代码如何实现执行与记账，便于逐项复核；系统级语义与理由归 `nooshare-design/architecture/backtest-implementation.md`。

## 数据与时间

- 价格口径：后复权（`hfq`），由调用方保证；引擎不做复权。
- T 日收盘后的目标组合，在 T+1 交易日按**开盘价**执行；成交价含滑点。
- 最后一日的目标组合不执行，记为 `NO_NEXT_SESSION` 差异。
- 日线 OHLC 无法还原盘中队列、先后顺序与真实部分成交；结果中的 `fill_policy` 明示为模拟成交，不是真实逐笔撮合。

## 订单生成

- 目标股数 = `权重 × 上一交易日收盘总资产 ÷ 执行日开盘价`，按 A 股整手（默认 100 股）向下取整。
- 与目标持仓比较产生 BUY/SELL；同日先卖后买，释放现金供买入。
- 买入股数再受可用现金约束，现金不足则部分成交并记 `INSUFFICIENT_CASH` 差异。

## 交易规则（按执行日）

| 规则 | 判定 |
|---|---|
| T+1 | 当日买入当日不可卖（`bought_today`） |
| 停牌 | `is_suspended` 或 `volume == 0`（`volume=None` 表示未知，仅按标记判定） |
| 涨停 | `is_limit_up` 禁买 |
| 跌停 | `is_limit_down` 禁卖 |
| ST | `is_st` 禁买，卖出不限 |
| 假跳空 | `abs(ret) > 0.21` 当日不成交，与基线一致 |

每条拒绝都进入 `Order.reason` 与 `TargetDeviation.reason`。

## 成本公式（与 Strategy 基线逐位对齐）

- 买入等效价：`px × (1 + slippage_bp×1e-4) × (1 + commission_bp×1e-4)`
- 卖出等效价：`px × (1 - slippage_bp×1e-4) × (1 - (commission_bp + stamp_bp)×1e-4)`
- 默认：佣金 2.5bp 双边、印花税 5bp 卖出、滑点 5bp 双边、过户费 0。
- `Fill` 把滑点价与佣金/印花税/过户费分列，逐笔可复核；`CostSummary` 汇总。

## 账本与净值

- 持仓成本为移动加权平均，含买入费用；卖出按平均成本结转。
- 现金逐笔变化写入 `ledger`；每日收盘追加 `MARK` 记录。
- 净值 = `(现金 + 持仓市值) / 初始现金`；缺失行情按最近成本估值。

## 指标公式

- 年化交易日：244（与基线一致）。
- 年化收益：`期末净值^(244/交易日数) - 1`。
- 最大回撤：`min(净值 / 历史峰值 - 1)`。
- 年化波动率：日收益样本标准差 × √244。
- 换手率：`Σ|成交价×股数| / 平均总资产`；年化换手 = 换手率 / 年数。
- Sharpe：年化收益 / 年化波动率（无风险利率取 0）。
- 短样本年化指标（如两日 Fixture）数学上可读但不具统计意义，仅用于公式验证，不用于策略评价。
